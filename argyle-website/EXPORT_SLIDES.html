📊 How to Import Your Presentation into Canva

🎯 Best Method: Screenshot Each Slide

Step 1: Open Your Presentation

Open ARGYLE_PRESENTATION.html in your browser and press F11 for fullscreen.

Step 2: Take Screenshots

Windows Method:

  • Press Win + Shift + S to open Snipping Tool
  • Select "Full Screen" or drag to capture the entire slide
  • Save as: Slide1.png, Slide2.png, etc.

OR use Browser Extension:

  • Install "Full Page Screen Capture" extension for Chrome/Edge
  • Click the extension icon on each slide
  • It will automatically save the full slide

Step 3: Import to Canva

  1. Go to canva.com
  2. Click "Create a design" → "Presentation" (16:9 ratio)
  3. Click "Uploads" in the left sidebar
  4. Drag and drop all your slide screenshots
  5. Drag each image onto a new slide
  6. Adjust to fit the slide perfectly
💡 Pro Tip: Use the arrow keys in your presentation to quickly navigate between slides, then screenshot each one. Name them in order (Slide1, Slide2, etc.) so they're easy to organize in Canva.

🔄 Alternative: Print to PDF Method

Step 1: Convert to PDF

  1. Open ARGYLE_PRESENTATION.html in Chrome/Edge
  2. Press Ctrl + P (Print)
  3. Select "Save as PDF" as destination
  4. Set margins to "None" and background graphics ON
  5. Save as Argyle_Presentation.pdf

Step 2: Import PDF to Canva

  1. In Canva, go to "Uploads"
  2. Upload your PDF file
  3. Canva will split it into individual pages
  4. Drag each page onto a slide
⚠️ Note: PDF method may not preserve all animations and effects perfectly. Screenshot method gives you the exact visual result.

🎨 Manual Recreation (If Needed)

If you want to edit the content in Canva, you can:

  1. Use the screenshots as reference
  2. Recreate the design using Canva's tools
  3. Use these exact colors:
    • Blue: #38BDF8
    • Purple: #A855F7
    • Pink: #EC4899
    • Background: #0F172A
  4. Apply glass morphism effects using Canva's blur and transparency tools
